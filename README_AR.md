# Desktop — Android Hybrid Desktop Environment

هذا مستودع مشروع Android أصلي بواجهة سطح مكتب مستوحاة من Windows 11، مع فصل واضح بين:
- واجهة سطح المكتب وإدارة الملفات.
- محركات التشغيل المحلية التي ستُدمج تدريجياً.
- الاتصال ببيئة Windows سحابية/بعيدة.

## بناء APK عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم `Desktop`.
2. افتح تبويب Actions.
3. شغّل `Android APK` أو ادفع commit جديداً إلى `main`.
4. نزّل artifact باسم `Desktop-debug-apk`.

## ملاحظات توافق مهمة
- Android لا يشغّل ملفات Windows EXE مباشرة.
- تشغيل EXE محلياً يحتاج طبقة توافق مثل Wine مع Box64/Box86، وتوافقها يعتمد على معمارية الملف والجهاز.
- بعض برامج Windows تحتاج تعريفات أو خدمات Kernel أو DirectX ومكونات لا يمكن توفيرها على Android.
- دعم Python/Node ومكتباتهما يحتاج تضمين runtimes وإدارة اعتماديات؛ لا يمكن ضمان جميع المكتبات أو الحزم.
- وضع السحابة يحتاج جهاز Windows فعلياً أو مزود Windows Cloud، مع إعداد اتصال آمن. هذا المستودع لا يتضمن خادماً أو اشتراكاً سحابياً.

## الخطوة الهندسية التالية
إضافة طبقة `RuntimeProvider` مستقلة، ثم ربط Python محلياً، وLinux userspace، ثم Wine/Box64 للأجهزة المتوافقة، وأخيراً عميل RDP/بوابة سحابية.
